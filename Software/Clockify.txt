====== Clockify ======

[ @timer @saas @web @api ]

Китайский сервис для учета времени. Можно в соло, можно на уровне компании.

Можно держать открытым окно браузера. При запуске таймера имя вкладки превратится в счетчик цифр.

Можно поставить в браузеры расширение. Таймеры можно запускать/останавливать, но иконка расширения не подсказывает, работает ли сейчас какой-то таймер. 

Можно установить их десктоп-аппу, будет отображаться в трее. Проблема — в трее отображается статичная иконка, ничего не подсказывает, запущен ли сейчас таймер или нет. И в какой-то момент свёрнутое приложение (походу, браузер на Electron) не развернулось.

Можно поставить приложение на смартфон. Есть два виджета, и при запуске таймера появляется иконка в тулбаре, но работают эти виджеты бестолково. Если запускать таймер в приложении, то иконка в тулбаре не появляется и ничего не подсказывает, что таймер работает.

===== Виджет на рабочем столе Plasma =====

Можно подключиться к clockify через виджет Plasmai, который сперва нужно установить любым стандартным способом.

Оттуда к сервису clockify будут ходить запросы по API. Если API для бесплатного тарифа, то будут сложности, лимит подключений очень небольшой. 

==== Получить токен для API ====

В правом верхнем углу иконка профиля
> Preferences
> Advanced
> Manage API keys

В настройках виджета Plasmai выбрать провайдера clockify и указать свой токен (его можно тут же сохранить в kwallet).

В настройках виджета можно выставить большой интервал запросов (по-умолчанию там 30 секунд):

Display
> Updates
> Refresh interval (seconds) = 300

Не факт, что поможет.
