====== yt-dlp ======

[ @console @youtube ]

Утилита для скачивания с Youtube видео или аудио из видео. Отпочковалась от ''youtube-dl''. 

В Youtube эти утилиты очень не любят и периодически что-то меняют в выдаче своих видео, отчего утилита временно перестаёт работать.

===== Установить =====

[[Debian:Install:yt-dlp]]

===== Сделать скрипт для скачивания видео =====

{{{code: lang="sh" linenumbers="True"
    # Full manual https://github.com/ytdl-org/youtube-dl/blob/master/README.md

# === Start ===

--js-runtimes node:/usr/bin/node

# === VIDEO FORMAT ===

    # Download mp4 format available but no bigger than %number_set%
--format '[height<=2000][ext=mp4]' # Сюда попадает 1080
#--format '[height<=720][ext=mp4]'
#--format '[height<=480][ext=mp4]'
#--format '[height<=360][ext=mp4]'

    # Do not use the Last-modified header to set
    # the file modification time
--no-mtime

    # Download only the video, if the URL refers to a video and a playlist.
    # Это не мешает скачивать плейлисты по отдельным линкам,
    # но помогает на накачать лишнего.
--no-playlist

# === DOWNLOADING ===

    # Save all videos under /home/astenix/Видео/
        # KISS, and don't use spaces in folder names.
    # AND set filename simple, with ID of their youtube uploader.
    # НЕВОЗМОЖНО СКАЧИВАТЬ В КАТАЛОГИ С ПРОБЕЛАМИ В НАЗВАНИИ
-o $HOME/Видео/'[%(uploader)s] %(title)s.%(ext)s'

    # Do not overwrite files if already available
--no-overwrites

# === FILENAMES ====

--trim-filenames 175

# раньше было '%s', затем yt-dlp потребовало использовать '%q', 
# потому что %s слишком опасно для команд в --exec
# А еще пришлось убрать лишние кавычки
--exec "bash $MY_SCRIPTS/youtube/normalize_title.sh %(filepath)q"

    # (НЕ НАДО) Restrict filenames to only ASCII characters, and avoid "&" and spaces
    # in filenames - но тогда все слова будут разделены _ подчеркиванием
# --restrict-filenames

# === ON SITE ===

    # At youtube
--mark-watched


}}}

В строке 42 поменять путь к скрипту нормализации заголовка скачанного файла (если такой используется).

Сделать алиас для этого скрипта в ''~/.bashrc'':

	''# video''
''alias yv="/usr/local/bin/yt-dlp --config-location $MY_SCRIPTS/youtube/download_video" # скачать видеоролик''

и скачивать все видео через алиас “''yv”'':

''yv https://www.youtube.com/watch?v=V-J6hep_y4o''

===== Выгрузить плэйлист с Youtube =====

У меня в плейлисте «Смотреть позже» собралось 1450 вхождений. Можно скачать все ссылка на видео из этого плейлиста через yt-dlp в .txt и ещё тонко подкрутить имя и ссылку на видео:

''yt-dlp --cookies-from-browser firefox \''
	''--flat-playlist \''
	''--print "%(channel)s | %(title)s | %(webpage_url)s" \''
	''"https://www.youtube.com/playlist?list=WL" \''
	''> youtube_WL.txt''

===== Скачать видео и аудио по-отдельности =====

В настройках скачивания разумно указать большое разрешение файлов. 

Всегда есть вероятность, что какой-то видеоролик в принципе невозможно скачать. Но иногда его невозможно скачать только потому, что я хочу mp4, а оригинальное видео было сделано (и залито на Youtube) в другом формате. Или исходное видео очень низкого разрешения. Во всех этих случаях yt-dlp сообщит, что не может скачать запрошенное видео, но при этом он может дать общую подсказку: 

 ''Requested format is not available. Use --list-formats for a list of available formats''

''yv --list-formats'' [[https://www.youtube.com/watch?v=sKp70tBqUXc|''https://www.youtube.com/watch?v=sKp70tBqUXc'']]

==== Решение ====

1) 

Можно скачать файл с видео (см. параметр ''video only'' в указанной строке), указав параметр по id (первая колонка): 

''yv -f 604'' [[https://www.youtube.com/watch?v=sKp70tBqUXc|''https://www.youtube.com/watch?v=sKp70tBqUXc'']]

2) 

И файл с аудио:

''yv -f 140'' [[https://www.youtube.com/watch?v=sKp70tBqUXc|''https://www.youtube.com/watch?v=sKp70tBqUXc'']]

Иногда есть возможность выбрать кодек аудио, потому что mp4 это всего лишь контейнер, звук внутри может быть ''opus'' или ''aac''. Мы предпочитаем ''aac''.

3)

В общем, скачали два файла, назовем их условно ''01.mp4'' и ''01.m4a''. Их можно соединить или через ПО для монтажа видео ([[DaVinci Resolve]]), или в консоли через [[FFmpeg]]:

''ffmpeg -i 01.mp4 -i 01.m4a -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac 02.mp4''

Получить файл ''02.mp4'', смотреть.
