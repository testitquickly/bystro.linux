====== Codex ======

[ @ai @openai @codex ]

Это агент от OpenAI.

Оплатить подписку на ChatGPT Plus за 20$. Первый месяц бесплатно.

===== Установить =====

''curl -fsSL'' ''https://chatgpt.com/codex/install.sh'' ''| sh''

В будущем использовать этот же способ для обновлений. 

===== Авторизация =====

В терминале:

''codex login''

Выбрать ”Sign in with ChatGPT”. Откроется браузер для авторизации.

Использовать Codex без отдельной оплаты API в пределах лимитов подписки (1000 запросов в день).

===== Справочная =====

''codex --help''

===== Общение =====

В терминале:

''codex''

Откроется интерактивный интерфейс Codex. Можно напечатать вопрос или задание, нажать Enter.

Начать диалог в контексте проекта:

* сперва зайти в каталог с рабочими файлами, 
* дальше упомянуть их название — агент их увидит и сможет с ними работать.
* если файлы — симлинки, то агент не сможет с ними работать (записать изменения)

Команды в чате:

  /init - create an AGENTS.md file with instructions for Codex
  /model - choose what model and reasoning effort to use
  /status - show current session configuration
  /statusline - настроить информационную строку в низу экрана с чатом
  /permissions - choose what Codex is allowed to do
  /review - review any changes and find issues

===== Выход =====

''Ctrl+C'' или команда ''/quit''

===== Продолжить предыдущий диалог =====

* зайти в каталог, в котором уже был чат
* ''codex resume''

===== Посмотреть чаты =====

…независимо от рабочего каталога

''codex resume --all''

==== Переименовать чат ====

Если не вводить новое название, Codex сам предложит что-то.

''/rename Новое название''

==== Удалить чат ====

В этом режиме невозможно удалять чаты, их можно только архивировать

''Ctrl+a''

Если надо удалить чат — сперва открыть интерфейс управления агентами.

===== Посмотреть агентов =====

Это похоже на вызов списка чатов, но это уже интерфейс управления агентами (AI-исполнитель, который может самостоятельно читать и изменять файлы, запускать команды, анализировать результаты) и чатами с ними:

''codex agents''

==== Группировка агентов ====

По модели, каталогам, проектам, статусу:

''g''

==== Удалить агента (чат) ====

Переместить фокус курсора на нужный:

''backspace''

===== Перейти в другой каталог =====

1. Прекратить текущий чат явной командой выхода: ''/exit''

Можно сделать ''Ctrl+C'', но это способ экстренно прервать задачу, при этом сам Codex, скорее всего, останется открытым и продолжит работу.

2. в терминале перейти в нужный каталог
3. открыть список сохранённых разговоров:

''codex resume --all''

и выбрать нужный чат. Если появится вопрос о рабочем каталоге — выбрать  каталог.

Есть смысл сделать алиас в .bashrc для выбора чатов, и первым шагом сделать переход в рабочий каталог:

''for i in cddr сввк; do alias $i='cd $HOME/analyze-this && codex resume --all'; done # список чатов Codex''

===== Лимиты =====

У каждого чата есть контекстное окно по расходу токенов. Проверить:

''/status''

Можно настроить отображение ряда параметров в статусной строке чата:

''/statusline''

Также надо отслеживать лимиты на расходы в своём аккаунте: https://chatgpt.com/settings/usage?tab=overview

===== Переключить модель =====

Это нужно для уменьшения расхода токенов. Да и просто разумно переключаться между моделями в зависимости от сложности задачи.

==== Установить модель по-умолчанию ====

''mcedit  ~/.codex/config.toml''

Здесь:
* ''tui'' означает Text User Interface, то есть интерфейс Codex в терминале: поле ввода, меню, список сеансов.
* ''nux'' означает New User Experience — подсказки о новых возможностях. 
* строка ''"gpt-6.1-sol" = 2'' будет показывать подсказки о доступности этой модели.

Записать нужную модель первой строкой:

''model = "gpt-5.6-luna"''

''[tui]''
''screen_reader_detection_done = true''
''resume_cwd = "current"''
''session_picker_view = "dense"''

''[tui.model_availability_nux]''
''"gpt-6.1-sol" = 2''

Сохранить изменения и запустить новый сеанс Codex. 

Учесть, что модель и уровень «разумения» сохраняются в каждом чате отдельно, поэтому изменение отобразится только на всех новых чатах. В старых переключить модель надо вручную. 

==== Поменять модель на ходу ====

В Codex CLI:

''/model''

Выбрать “''Sol''” и уровень рассуждения, если появится такой выбор. Модель сменится в текущем сеансе, история переписки сохранится.

==== Поменять уровень рассуждений действующей модели ====

''Shift+up/down''

===== Настроить Shift+Enter в Konsole =====

1. Настройка → Изменить текущий профиль → Клавиатура.
2. Выбрать текущую схему и [Изменить].
3. Найти строку Return+Shift.
4. Заменить её значение на:
   ''\E[13;2u''
5. Сохранить изменения

Konsole будет передавать отдельное сочетание Shift+Enter, которое Codex сможет распознать.
