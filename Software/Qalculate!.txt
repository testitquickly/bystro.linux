====== Qalculate! ======

[ @console @qalculate ]

===== Установить =====

''sudo apt install qalculate-qt''

===== Настроить =====

Важно настроить его правильно, чтобы в будущем не страдать от ерундовых отклонений в цифрах.

Режим (первая иконка в интерфейсе)
> Режим общего отображения = Обычный
> Приближение = Автоматическое
> Основание системы счисления = Десятичное
> Основание для выражения = Десятичное
Отображение чисел 
	= Обычное
	= Показывать конечные нули
	= Округлять половинные числа вверх
	= Экспоненциальная форма комплексных чисел

==== Результат вычислений ====

''Параметры''
''> Числа и операторы''
''> Режим отображения интервалов'' = Плюс/Минус
''> Округление ='' Округлять половинные числа к нулю

''Параметры''
''> Разбор и вычисление''
''> Статус выражения'' = В поле выражения
''> Выражение в истории'' = Введенное
''> Выражение после расчёта'' = Сохранить выражение
''> Режим анализа'' = адаптивный
''> Упрощенный процентный расчёт'' = Да
''> Точность чтения'' = без галочки

Последнее самое важное, иначе при условном ''10.41*20'' вместо  ''208,2'' будет отображаться очень точный ответ, который будет выглядеть странно = ''208,20±0,10''
