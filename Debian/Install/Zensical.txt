====== Zensical ======

[ @debian @install @zensical ]

Следуем https://zensical.org/docs/get-started/

===== Установить =====

==== в систему ====

''pipx install --python /usr/bin/python3 zensical''

Всё будет установлено в каталог ''~/.local/share/pipx/venvs/zensical/''

==== в проект ====

Подразумевается, что в корневом каталоге проекта уже есть (или будет) каталог ''docs/''.

Перейти в корневой каталог проекта и

''zensical new .''

Появятся следующие файлы:

''.''
''├─ .github/''
''├─ docs/''
''│  ├─ index.md''
''│  └─ markdown.md''
''└─ zensical.toml''

===== Запуск сервера =====

''zensical serve''

Открыть в браузере ''http://localhost:8000''

==== То же компактно ====

Будет поднят в каталоге ''docs-site''

''mkdir docs-site && cd docs-site''

''python3 -m venv .venv''

''source .venv/bin/activate''

''pip install zensical''

''zensical new .''

Положить в каталог ''docs-site/docs'' файлы *.md и запустить сервер Zensical:

''zensical serve''

Открыть в браузере ''http://localhost:8000''

При изменении в файлах *.md изменения будут автоматически отображаться на сайте.
