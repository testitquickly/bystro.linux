====== bash ======

[ @bash @konsole @sh ]

В начале каждого выполняемого скрипта надо вставлять

''set -euo pipefail''

''-e'' — остановить скрипт, если какая-то команда вернула ненулевой код (упала)

''-u'' — остановить скрипт при обращении к незаданной переменной

''-o pipefail'' — конвейер считается упавшим, если упала любая команда внутри него

===== Отладка скрипта =====

Запустить файл *.sh через 

''./abc.sh -x''

Перед каждой командой будет выведена информация с подставленными значениями переменных.
